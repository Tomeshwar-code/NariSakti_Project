# Theme folder

This folder contains the core theme styles for the NariSakti frontend UI.

Files:
- `variables.css` — global color, spacing, typography, and shadow variables.
- `typography.css` — base text, heading, and body styles.
- `layout.css` — container, page structure, dashboard, and general layout utilities.
- `effects.css` — glass panels, badges, animations, and visual helpers.
- `forms.css` — input, label, form field, and form action styles.
- `index.css` — entrypoint that imports all theme pieces.
